# Contributing

## Scope

This repository is an OpenCode integration template for the upstream [MemPalace](https://github.com/MemPalace/mempalace) project.

Please keep that distinction clear in pull requests, issues, and docs.

- Changes to this repo should focus on OpenCode setup, template ergonomics, documentation, and local integration guidance.
- Bugs or feature requests in the MemPalace memory engine itself should be filed against the upstream `MemPalace/mempalace` repository.

## Upstream Attribution

MemPalace is the upstream project this template is built around.

- Upstream repo: `https://github.com/MemPalace/mempalace`
- Upstream author reference from project metadata: `milla-jovovich`

When editing this repo, preserve clear attribution to the upstream MemPalace project and avoid wording that implies this template created or owns MemPalace itself.

## Local Changes

Typical contributions here include:

- README improvements
- OpenCode config examples
- AGENTS.md guidance
- setup script improvements
- repo hygiene like `.gitignore` and template polish

## Pull Requests

Keep changes small and practical.

Before submitting:

1. Verify docs still match the included `opencode.json`, `AGENTS.md`, and `setup.sh`.
2. Keep upstream MemPalace references intact.
3. If you mention MemPalace behavior, prefer linking to the upstream repo rather than restating unsupported claims.
